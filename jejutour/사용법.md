# 제주 헤리티지 자율주행 택시 — 사용법

## 화면
| 파일 | 누가 | 내용 |
|---|---|---|
| `index.html` | 학생 | 번호(1~30) → ① 테마 → ② 추천 3곳 → ③ 코딩 미션 → ④ 코스 카드·저장·보내기 |
| `teacher.html` | 선생님 | 30명(번호) 제출 현황, 경로 다시 달리기(음성), 🖥 발표 화면 |
| `tools/calibrate.html` | 선생님 | 새 지도 그림 맞추기 (격자·바다/산 칸·출발 칸·기준점) |

## 학생 미션 규칙
- 블록을 **끌어다 붙이고**(톡 누르면 맨 아래에 붙음) **▶ 실행** · 블록을 떼면 그 블록만 분리 · 블록 끝 ✕ 또는 왼쪽 블록 칸에 놓으면 지우기
- 🔁 반복 블록은 ㄷ자로 벌어져 있어요. 안에 블록을 끌어 넣으면 벌어지며 채워져요(반복 안에 반복도 가능)
- 칸에 땅이 조금이라도 있으면 지나갈 수 있고, 칸 전체가 바다면 "바다예요"로 막혀요
- 위쪽 단계 탭(① 테마 ② 코스 ③ 코딩 ④ 완성)을 누르면 이전 단계로 돌아가요 · ↺ 초기화는 번호만 남기고 처음부터
- 추천 3곳은 서로 **2칸 이상** 떨어진 곳으로 골라요
- (누를 때마다 공항에서 다시 출발)
- 장소 칸에서 **🔊 말하기** 또는 **💬 말풍선**으로 "여기는 ○○입니다" → 헤리티지 스탬프 + 탐험 미션
- 점수: 스탬프 ×100 · 🔁 반복 블록 +30(최대 3개) · 블록 15개 이하 +50 · 부딪힘 −20
- 코드를 고치면 스탬프는 다시 실행해서 받아요
- 음성이 안 나오는 기기는 말풍선으로만 보여줘요

## 핑퐁 스크래치로 옮기기
1. ④에서 **💾 핑퐁 스크래치 파일 저장** → 태블릿 다운로드 폴더에 `.sb3`
2. https://scratch.roborisen.com → 모둠 **그룹 ID** 선택 → Start
3. 파일 → **컴퓨터에서 불러오기** → 저장한 파일
4. 오토카 연결 → 🏁 깃발 (오토카를 출발 칸에 오른쪽을 보게 놓기)
- ⚠️ 오토카를 연결하지 않으면 "회전하기" 블록에서 멈춰 기다려요
- TTS(말하기)는 인터넷이 필요해요

## 설정 (`config.js`)
- `SERVER_URL`: 구글 Apps Script 주소 (비우면 연습 모드 / 선생님 화면은 예시 데이터)
- `CLASS_SIZE`: 30
- `THEMES`, `SCORE`: 테마 이름·색, 점수 규칙
- 지도: `BG_IMAGE`, `GRID`, `GRID_COLS/ROWS`, `MAP`, `START`, `MAP_POINTS` ← **새 지도는 `tools/calibrate.html`이 만들어 줘요**
